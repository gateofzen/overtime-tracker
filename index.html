ショートカット URL

以下のURLを iOS ショートカット / Android オートメーション の「URLを開く」アクションに設定すると、ボタンを押さずに打刻できます。

出勤中なら退勤、勤務外なら出勤を自動判定。1つのショートカットで完結。

設定方法 (iOS / Android)
iOS (ショートカット.app):
① ショートカットを新規作成 → 「URLを開く」アクション → 上記URLを貼り付け
② オートメーション → 個人用 → 到着時 → 場所:病院 → 上記ショートカットを実行
(退勤用は「出発時」のオートメーションで設定)

Android:
MacroDroid / Tasker / Automate などで「位置情報トリガー」 → 「URLを開く」
または Google アシスタントの「ルーティン」機能から設定可能。

スプレッドシート

勤務表データが反映されない場合や、書式を最新にしたいときに使います。

出勤簿の出力

月末に紙で提出する救命救急センター出勤簿を、指定月のシートデータから Google スプレッドシートとして自動作成します。作成後は A4縦の印刷用PDFを直接ダウンロードできます。

時間外勤務のルール

日勤 正規 17:30 / 上限 18:00
夜勤・25勤明け 正規 9:30 / 上限 10:00

原則、上限を超える退勤は自動的に上限で丸められます。
上限を超えて働いた場合は、退勤打刻時に 理由を付けて延長申請 することで、実退勤時刻が記録されます。
後から追加・修正する場合は、打刻履歴の「編集」ボタンから理由を入力できます。

打刻ログの同期

打刻データ (出勤/退勤時刻) を Google ドライブに保存し、他のデバイスと共有します。 アプリ起動時や打刻時に自動的に同期されますが、うまく同期されていないと思ったら手動実行してください。
