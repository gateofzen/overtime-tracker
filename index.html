ショートカット URL

以下のURLを iOS ショートカット / Android オートメーション の「URLを開く」アクションに設定すると、ボタンを押さずに打刻できます。

出勤中なら退勤、勤務外なら出勤を自動判定。1つのショートカットで完結。

設定方法 (iOS / Android)
iOS (ショートカット.app):
① ショートカットを新規作成 → 「URLを開く」アクション → 上記URLを貼り付け
② オートメーション → 個人用 → 到着時 → 場所:病院 → 上記ショートカットを実行
(退勤用は「出発時」のオートメーションで設定)

Android:
MacroDroid / Tasker / Automate などで「位置情報トリガー」 → 「URLを開く」
または Google アシスタントの「ルーティン」機能から設定可能。
